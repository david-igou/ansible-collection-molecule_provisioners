# david_igou.molecule_provisioners.qemu

Local QEMU virtual machines as Molecule instances. Scenarios use it through the collection's
`create`, `prepare` and `destroy` playbooks.

- [Role reference](https://david-igou.github.io/ansible-collection-molecule_provisioners/qemu_role.html), also available as
  `ansible-doc -t role david_igou.molecule_provisioners.qemu`
